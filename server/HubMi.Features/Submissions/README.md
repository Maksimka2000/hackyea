# Submissions

Signed-in residents, NGOs and local governments send needs, ideas (idea card: essence, target group, stage), good practices /
micro pilots and local challenges (JST only), follow the status and talk to ROPS staff. Staff monitor the inbox, open
(which marks seen), reply, change status, moderate or reject, link innovations and turn an idea into a draft library card.
Rules that must always hold (status flow, first response time, who may write) live on `Domain/Submissions/Submission`.
