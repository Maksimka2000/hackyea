# UI

This folder contains reusable UI building blocks.

If a component can be used in many features without knowing business details, it probably belongs here.

## Examples

- buttons
- inputs
- badges
- cards
- modal shells
- empty-state wrappers

## Folder split

- `primitives`
  Small reusable building blocks
- `composite`
  Reusable combinations of primitives

## Rule

Do not move a component here just because it is large.

Move it here only when it is generic and reusable across multiple features.
