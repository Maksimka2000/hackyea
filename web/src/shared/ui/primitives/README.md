# Primitives

This folder is for small reusable UI building blocks.

These are the simplest components used to build larger screens.

## Good examples

- `Button`
- `Input`
- `Textarea`
- `Badge`
- `Spinner`
- `IconButton`

## Expectations

Primitives should be:

- generic
- accessible
- easy to reuse
- driven by shared design tokens and utility classes

## What should stay out

- feature-specific names or logic
- API calls
- business rules

If a component sounds product-specific, it likely does not belong here.
