# Public Group

This route group is for public-facing routes.

These are screens the user can open without being inside the main app area.

## Good examples

- home page
- pricing page
- about page
- docs landing page
- legal pages
- public onboarding entry screens

## Why use a route group

It lets you organize public pages separately from auth pages and the main app shell.

This keeps the routing layer easier to understand as the project grows.
